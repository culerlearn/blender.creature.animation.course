# Rigging and Animating a Creature

Companion repository for the [CulerLearn](https://www.culerlearn.com) course of the same name. Model, rig, and animate a four-legged creature in Blender, then bring it into Three.js and build the environment it crawls through.

## Course Structure

| Part | Topic | Status |
|---|---|---|
| 1 | Modelling and Rigging a 4-Legged Creature | Live |
| 2 | Animation and Lateral Movement | Live |
| 3 | Exporting to Three.js | In production |
| 4 | Building the Crawl Environment | In production |
| 5 | Final Scene | In production |

Full lesson content, video walkthroughs, and written breakdowns live on [CulerLearn](https://www.culerlearn.com), this repo holds the project files, not the course itself.

## What's Here Now

Parts 1 and 2 are pure Blender work, modelling, bone structure, skinning, and animation, covered in the videos themselves. No code or starter files are needed for these two parts.

Parts 3 through 5 bring the rig into a VS Code and Three.js project. Starter files, the base project scaffold, and any assets needed to follow along will be added here as each part is recorded.

## Prerequisites

- Basic familiarity with Blender's interface (Parts 1-2)
- Basic familiarity with VS Code (Parts 3-5)
- No prior rigging, animation, or Three.js experience required, everything is built from nothing in the course itself
